# Moon and Moss Apothecary

Responsive one-page small-business site built from the approved visual mockup.

## Preview locally
Open `index.html` in a browser, or run a tiny local server:

```bash
python3 -m http.server 8080
```

Then open http://localhost:8080.

## Before launch
Update these client-specific details:
- Shop/shipping destination links (`href="#shop"` currently scrolls to the product section)
- Contact email in the contact strip
- Upcoming market cards in `index.html`
- Social links in the footer/top bar
- Any final product names or photos

## Hosting
This is a static site and can deploy directly to Cloudflare Pages, Netlify, Vercel, or any standard web host. No build step is required.
